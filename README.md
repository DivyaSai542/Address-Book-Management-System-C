# Address-Book-Management-System-C
## Overview

The Address Book Management System is a menu-driven console application
developed in C to store and manage contact information.

The application provides functionality to add, search, edit, delete,
and display contact details. File handling is used to provide persistent
storage of contact information across program executions.

## Features

- Add new contacts
- Search for contacts
- Edit existing contact information
- Delete contacts
- Display all saved contacts
- Store contact information using file handling
- Menu-driven user interface
- Modular program design

## Technologies Used

- C Programming
- Structures
- Pointers
- Arrays
- Strings
- Function Pointers
- File I/O
- Modular Programming

## Contact Information

The application manages contact details such as:

- Name
- Phone Number
- Other stored contact information

The application implements the following operations:
